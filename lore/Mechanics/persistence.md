# Persistence

The world is meant to be saved as it is generated, so places, villagers and what the Wanderer did there stay. Most lore about remembered villages and slow reveals depends on this. The rules themselves are in the [README](../README.md); this file holds the open questions.

## Canon

- Rules (world persistence, start and death in a village, scope, dialogue rules): see [README](../README.md#ground-rules).
- **Persistent villages make the slow reveal possible:** which monks are dark is learned over time. (rounds 7–8)
- **Found shrines persist through the Whisper.** (round 10)

## Open

- **Finite loot.** If areas are saved, searched props stay empty. Do runestones and reliquaries ever refill? If not, the world thins and players push outward (fits the tone).
- **Hollows thin out** (consequence of loose-soul rules B1 + B4): each kill uses up a corpse for good; hatred Hollows and pyres use up more. Proposal: accept it; Hollow counts per area need a corpse budget. See [Hollows](../Characters/hollows.md).
- **Bag position** needs saving for the death rules: see [Death](death.md).

## Rejected

- **Online griefing safeguards** (no utterances in villages; released things hunt only the speaker). Dropped round 4: single-player. Revisit if online returns.
